# Bat TV Browser — Motor Mozilla GeckoView 132.0 (Google TV & Onn TV)

Este directorio contiene la configuración nativa de **Mozilla GeckoView (última versión estable 132.0)** para **Chromecast con Google TV 1080p** y **Onn TV Box**, con las 3 extensiones preinstaladas:
1. **uBlock Origin** (`resource://android/assets/extensions/ublock_origin/`)
2. **Popup Blocker (strict)** (`onNewSession -> null` + WebExtension estricta)
3. **Violentmonkey** con el script **FastForward / Bypass All Shortlinks** preinstalado.
